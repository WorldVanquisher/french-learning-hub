# FLH-053 local embedding contract probe

Go standard library plus the repository's **existing HTTPProvider** and current
renderers. No model runtime, download, dependency installation or production
configuration change. Run from the repository root with existing cached modules:

```sh
GOCACHE=/tmp/flh049-go-cache GOPROXY=off GOSUMDB=off go test ./scripts/validation/flh053 -race -count=1 -v
GOCACHE=/tmp/flh049-go-cache GOPROXY=off GOSUMDB=off go build -o /tmp/flh053-probe ./scripts/validation/flh053
/tmp/flh053-probe -out /tmp/flh053-plain-new
/tmp/flh053-probe -payload rendered -require-unit-norm -out /tmp/flh053-rendered-new
```

Use another writable existing Go cache if needed. Default execution creates its
own loopback fake, never contacts a supplied service, and needs loopback socket
permission. The fake returns deterministic SHA-256-derived normalized vectors
and deliberately reverses response item order. It is not a language model.

`plain`: two batches, six positions, synthetic English/French text with repeats
and changed ordering. `rendered`: five batches, eleven positions, generated by
current production rendering for mixed Unit/Concept and document-only calls,
plus raw English/French search queries and a repeated mixed batch. No frozen
evaluation fixture is loaded. Inputs never receive E5 prefixes from this probe.

Only after a service/identity/run scope is supplied and approved, a **plumbing
only** command is available (placeholders are not a supplied endpoint):

```sh
/tmp/flh053-probe -allow-real-endpoint \
  -base-url "http://<WINDOWS_PRIVATE_IP>:<PORT>/v1" \
  -model "<EXACT_WIRE_DEPLOYMENT_ID>" -dimensions 768 \
  -max-requests 2 -max-inputs 6 -max-input-bytes 2048 \
  -request-timeout 5s -timeout 30s -atol 0.00001 -rtol 0.0001 \
  -require-unit-norm -norm-tolerance 0.001 \
  -out /tmp/flh053-supplied-endpoint-new
```

Expected dimensions, request and input-position limits must be explicit in
supplied-endpoint mode. Defaults/hard bounds: 5/8 requests, 16/24 positions,
2048/4096 UTF-8 bytes per input; 5s/30s per request and 30s/120s overall.
Floats/tolerances must be finite; tolerance flags are bounded to [0,.01]. The
numeric repeat check is per coordinate:
`abs(a-b) <= atol + rtol*max(abs(a),abs(b))`, within and across batches. Unit norm
is an optional separate check, not an assumed provider normalization step.
Declare these tolerances before a run; preserve failures instead of silently
loosening them.

Use `-payload rendered -max-requests 5 -max-inputs 11` to probe the three current
application input forms. It includes the raw-search role gap documented in the
[contract plan](../../../docs/plans/FLH-053-local-embedding-contract.md).
A strict future E5 role adapter should reject unsupported raw search payloads;
that failure is meaningful. Plain payload success says nothing about correct
E5 prefixes. This probe implements no adapter and accepts no semantic-quality,
role-adaptation, model revision or GPU claim from a successful vector response.

URL rules: private/loopback IP literal, http(s), no userinfo/query/fragment.
The base excludes `/embeddings`; HTTPProvider appends that suffix after trimming
trailing slashes. Named hosts/public addresses are refused. No key/environment
credential is read or sent. Ambient proxies, redirects and connection reuse are
disabled by the probe's explicitly supplied HTTP client; provider code is
unchanged. Calls stop at the first provider or additional-probe failure.

Output is a **new** `/tmp/flh053...` directory with an existing non-symlink parent,
or an automatically created temporary directory if `-out` is omitted. Existing
output and symlink ancestors are refused. `report.json` preserves synthetic
inputs, ordered vectors, norms, safe error categories, request/input counts,
input hashes, response hashes and HTTP statuses. Raw response bodies, headers
and endpoint addresses are not saved. `sha256.json` hashes the report.

Exit 0 = vector/transport checks passed; 1 = provider/probe failure with retained
evidence; 2 = configuration/output/encoding error. Build the binary to retain
these exact exits; `go run` wraps a child's nonzero code.

Self-tests distinguish provider rejection from additional checks: omitted/null
indices can decode as zero; uniformly wrong dimensions, zero vectors and
float32 overflow/underflow values can pass HTTPProvider but fail the probe. Normalization
and repeated-input tolerance are additional checks. The provider's untrusted
`error.type` echo is preserved as a tested observation; this probe reports only
safe categories. Fake listeners are stopped on exit; artifacts remain isolated
for review. No Windows/GPU or supplied-endpoint acceptance has occurred.
