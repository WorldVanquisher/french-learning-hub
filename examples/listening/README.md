# Synthetic listening transcript

`synthetic-lesson.fr.txt` is an authored, synthetic French transcript (a short
local-radio item about a new library) used by the Exam Listening Lesson v1
tests and the owner walkthrough in [docs/DAILY_USE.md](../../docs/DAILY_USE.md)
§9. It is not the transcript of any real video. Each line starts with a
timestamp, as a source that supplies timestamps would provide; a transcript
without timestamps is also accepted.
