# Practice prototype: which feed and grading fixtures the UI uses (2026-11-19, increment 5)

The practice prototype (`web/src/prototype/`) reads one generated module,
`web/src/prototype/extractionPracticeFixture.ts`. It is built only from the extraction lane's
**sealed** Extraction 2.1 handoff (`extraction2-20261119/handoff-2.1`, SHA256SUMS
`bad6f86e991179f1a0c911e0c4fb3ec1892dabe743da455712e0ded30cae2bc4`). That lane's live worktree is
never read.

```bash
python3 -I -B scripts/validation/extraction_practice/build_fixture.py --handoff HANDOFF_2_1 [--check]
```

## How it is checked

| When | What |
|---|---|
| Before the build | Both seals verify: the handoff's `SHA256SUMS` and the bundle's own. Every bundle file and the snapshot tar must be covered by the handoff seal |
| Before the build | A scratch overlay holds this tree's shared baseline `tools/extraction` with the sealed `snapshot/extraction21.raw.tar` (`857040c5…`) unpacked over it. It must reproduce `practice demo2 --check` and `practice workbooks-bundle --check`, and the regenerated bundle must equal `sample/workbooks/` byte for byte |
| Before every browser walkthrough | `walkthrough.py --handoff H` runs `build_fixture.py --check`. A missing or altered file stops the run (exit 2) before anything is built |
| In the page | `practiceFixture.ts` re-hashes all 21 texts (`sha256.ts`, no `crypto.subtle`, so it also works outside secure contexts). A mismatch or missing document stops the panel with the reason |

**What each part of the UI reads:**
- Review Today's practice rows and today's set read the feeds.
- Reveals and grading read the tutor packet whose source revision and SHA-256 equal the feed's
  (`joinConcept` refuses a pair from different revisions).
- "What you are about to share" and the copy read the study packet of the same revision.
- The tutor sessions read the two session packets, the returns and the previews.

**Grading parity:**
- 26 shared cases (`scripts/validation/extraction_practice/grading_cases.json`, all three grading
  fixtures).
- `grade_parity.py --handoff H` runs them through the sealed `practice.grade()`, and
  `practiceFeed.test.ts` runs them through the TypeScript mirror.
- The next-exercise rule and the agent-return classes are also checked against the sealed packets
  and previews (`practiceModel.test.ts`).

The French in every fixture is synthetic A1/A2 and needs a native-speaker check before learner use.
