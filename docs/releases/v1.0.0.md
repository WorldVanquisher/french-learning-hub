# French Learning Hub v1.0.0

French Learning Hub v1.0.0 is the first personal-use release: a local-first Go,
SQLite and React service that keeps French-learning questions as traceable
records. You can analyze each record, correct it, extract knowledge units from
it, and file those units under durable Concepts. Every Concept can be traced
back to the original question.

The release runs on one machine for one user, as one Docker image behind
`127.0.0.1`. It has no authentication. Do not expose it to a network you do not
trust.

## Highlights

- **A daily workflow from question to Concept.** Each learning record shows a
  stage summary (analysis → extraction → Concept decisions) with one next
  action. The summary is derived from the server's current records and is never
  stored. Links move between a record, the Concepts its units are filed under,
  their source records and AI suggestions. **← Back** returns you to where you
  were.
- **Advisory AI Concept suggestions** (opt-in, `SUGGESTION_PROVIDER=openai`).
  The model proposes existing Concepts for a small, explicitly selected batch
  of units, choosing from a bounded candidate list. Suggestions change nothing
  until you confirm one item at a time. A confirmation re-checks the current
  state, and a stale suggestion is refused. There is no bulk acceptance and no
  background work.
- **English and Simplified Chinese.** The interface supports English and
  简体中文. Generated explanations and unit statements are returned in both
  languages by the same explicit request.
- **Packaged release.** One Docker image (base images pinned by digest) holds
  the Go server and the built workbench. Compose binds it to `127.0.0.1` only.
  `/healthz` reports liveness and `/readyz` reports SQLite readiness.
- **A daily wrapper.** `scripts/daily/flh-daily.sh` runs the same Compose
  service with one private settings file every time. Its commands are `check`,
  `up`, `status`, `logs`, `stop`, `start` and `restart`, plus verified `backup`
  and `restore`.
- **A rehearsed upgrade and rollback.** You back up, keep the working image as
  `french-learning-hub:before-upgrade`, and upgrade. If the upgrade fails, you
  stop, retag and restore. This order was rehearsed end to end with real Docker
  in an isolated Compose project.

These remain available: capture import (`learning_capture_v1`, API, workbench
and `cmd/capture`), versioned analyses with append-only feedback, explicit
knowledge extraction, Concept Review (SAME, NEW CONCEPT, BROADER, NARROWER,
RELATED, DISTINCT, INVALID) and the read-only Knowledge Library. The optional
semantic search and the read-only research reports are also unchanged.

## Installing and upgrading

- **New install:** see `docs/QUICKSTART.md` and `docs/RELEASE.md`. For daily use
  with real providers, see `docs/DAILY_USE.md` §1–2. The commands for a clean
  install at this tag, and the health check, are collected in
  `docs/releases/v1.0.0-install.md`.
- **Upgrade of an existing daily instance:** follow `docs/DAILY_USE.md` §6
  *Upgrade*. Take a backup, tag the current image as `before-upgrade`, update
  the checkout to `v1.0.0`, then run `check`, `up` and `/readyz`.
- **Database schema:** v1.0.0 ships migrations `001`–`013`. An instance already
  at `013` starts without migrating. An older database is migrated forward
  when the service starts. Migrations are forward-only, so always back up
  first.
- **Rollback:** see `docs/DAILY_USE.md` §6 *Roll back a failed upgrade*:
  `stop` → retag `before-upgrade` as `local` → `restore <pre-upgrade backup>`
  → `/readyz`.

## Defaults and cost

- **Calls to a model.** With the defaults, nothing calls a model: the analyzer
  is rule-based, and extraction, suggestions and embeddings are disabled.
- **Billing.** With `openai` providers configured, only explicit actions call
  the provider and may be billed: requesting an analysis, requesting an
  extraction, or generating suggestions. Saving, browsing, switching language
  and confirming never call a model.

## How this release was validated

The full index is in `docs/validation/V1-RELEASE-EVIDENCE.md`.

- **`make verify`:** exit 0. It covers Go formatting, tests, vet, the
  builds, frontend typecheck, 322 frontend tests and the production build.
- **The daily-workflow acceptance fixture:** 43 passed, 0 failed. It runs
  against a local fake OpenAI-compatible provider.
- **Packaged upgrade and recovery,** rehearsed with real Docker Compose in an
  isolated project: 43 PASS, 0 FAIL. It covers the baseline, backup, upgrade,
  an induced failed upgrade, and recovery. After recovery the data was
  byte-identical to the baseline snapshot.
- **The packaged browser smoke** in real Chromium 156: 36 checks, 0 failed, all
  10 phases, run twice. It drives the record stage, the AI suggestion, the
  explicit SAME, both source records, back navigation with keyboard focus, the
  English ↔ 简体中文 switch, and the refusal of a stale confirmation. It also
  checks that read-only navigation sends no write. A controlled-failure probe
  showed that a failing smoke exits nonzero, keeps its evidence and removes
  only its own resources. The same workflow also passed on a GitHub-hosted
  runner on the pull-request commit of #126 (GitHub Actions run 42530700573).

## Known limitations

- **No authentication.** The service is loopback-only. Use the SSH tunnel
  described in `docs/DAILY_USE.md` §3.
- **The upgrade rehearsal did not migrate a database.** Both images had
  migrations `001`–`013`, so it proved an image upgrade and recovery. A
  database migration still needs a future release that adds one.
- **No down migrations.** Never start an older image on a newer database.
- **The fake provider proves mechanics, not judgment.** No automated check
  calls a real model. The quality of real-model suggestions is not measured.
- **The browser smoke ran in Chromium only.** No other browser and no
  narrow-screen layout were tested.
- **The public demo is separate.** This release does not deploy or change it.

## Not in this release

There is no review scheduling or mastery tracking, no automatic or bulk
application of AI suggestions, and no learned resolver.
